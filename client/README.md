# Personal AI Agent - Flutter companion client
#
# Companion Flutter client for the personal AI voice assistant.
# Adapted from lexxautomates/livekit_flutter_starter (fork of livekit/livekit-flutter-starter).
#
# The client dials into the same LiveKit server and agent as the voice/call
# surface, and gives the user a phone/laptop app for voice + text interaction.
#
# Substrate: lexxautomates/livekit_flutter_starter
# Backend:   the Python agent in agent/ (LiveKit agents SDK)
#
# Environment variables (in client/.env, not committed):
#   LIVEKIT_URL
#   LIVEKIT_API_KEY
#   LIVEKIT_API_SECRET
#   AGENT_ROOM_NAME  (optional)
